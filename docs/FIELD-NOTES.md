## Decision postcards

When a choice affects several later modules, add a tiny postcard:

```markdown
### Decision: [short name]

- Context:
- Choice for now:
- Consequence:
- Signal that should make us revisit it:
```

“For now” is important. Learning projects need reversible decisions more than
premature certainty.
